# BENCHMARK

[English](#english) · [简体中文](#简体中文)

## English

One experiment is one simulated plant at one gain set. Iterative methods receive
at most 20 runs including their measured start. Fixed/one-shot methods report
their actual counts; they do not repeat an identical measurement to consume 20.
Returned gains must reproduce the reported best cost. CMA-ES and BO now measure
the shared starting set first, within budget; sampled winners are returned,
never an unmeasured optimizer distribution mean.

The main benchmark starts from analytic Ku/Tu, including simplex/CMA/BO/hill:
this is oracle prior information, not a completely model-free experiment.
Offline expert generation and fitting are separate from deployment budgets.
Shrunk-ZN factors are selected on training families, not the evaluation plants.
The 7-run sweep costs seven per plant; failures use a common fixed non-oracle
prior instead of analytic Ku/Tu backfill. Results record recovered counts,
fallback policy and prior access. A failed sweep is not successful identification.

Current tables (generated by script 03, including actual budgets and provenance):

* [two_mass validation](../research/results/benchmark_table.md)
* [fixed-grid thermal test](../research/results/benchmark_table_thermal_deadtime.md)

two_mass has been used to compare vocabularies, reject lookahead and choose
policies. thermal_deadtime was defined after training and frozen at v0.4.1;
v0.5.0 reruns it after repairs, without choosing a new checkpoint on it. Neither
claim implies preregistration. The thermal result in v0.4.1 put vocabulary hill
climbing ahead of the head; that historical result remains in the changelog.
Current ranking must be read from the regenerated table even if a baseline wins.

The returned-best guarantee follows from measuring the start and saving the
minimum; it holds without the rollback gate. It is not evidence of safe
exploration: trials can diverge before a best point is returned. The gate's
effect is separately measured in [robustness.json](../research/results/robustness.json).
Per-plant gates do not suppress unrelated batch members. Trace-based risk and
coverage metrics use one record per measured transition; partial holds count.

```bash
python scripts/03_evaluate.py --plants 120 --budget 20
python scripts/03_evaluate.py --family thermal_deadtime --plants 120 --budget 20
python scripts/11_robustness.py
python scripts/23_sync_reference_docs.py
python scripts/16_check_claims.py
```

Manifests bind source, model/data hashes, seeds and environment. Source hashes,
rather than just the parent Git SHA of a dirty worktree, identify the measured
implementation. Claims checking covers registered artifacts and marked prose;
it does not prove every historical sentence or the method's causal advantage.

## 简体中文

一次实验指一个对象在一组增益下的一次仿真。迭代方法最多20次，包含实测起点；
固定与一次性方法列实际用量，不通过重复同一测量凑满20次。返回增益必须重现所报最优代价。
CMA-ES与BO现先测共同起点并计入预算，返回实际采样赢家，不再返回未测的分布均值。

主基准的simplex/CMA/BO/hill和head均从解析Ku/Tu出发，属于oracle先验，不能称完全无模型。
离线专家数据与训练成本独立列账；缩小ZN系数在训练族选择。7次扫描逐株计费；失败后各扫描方法
采用相同固定非oracle先验，不再回填解析Ku/Tu。产物记录恢复数、回退规则和先验来源；扫描失败不算辨识成功。

当前表格由03脚本生成，含实际预算与来源：

* [two_mass验证族](../research/results/benchmark_table.md)
* [固定网格热工测试族](../research/results/benchmark_table_thermal_deadtime.md)

two_mass参与过词表、lookahead和策略选择。thermal_deadtime在训练后定义，于v0.4.1冻结；
v0.5.0修复正确性后重跑，未据此选择新权重，但仍不构成预注册研究。
v0.4.1热工结果中同词表爬山优于head，该历史记录保留在CHANGELOG；当前排名以新生成表格为准，
基线胜出也照实发布。

最终不差于起点来自“实测起点并保存历史最小值”，关闭回滚门仍成立，不证明探索过程安全，
候选试验仍可能发散。门的实际效果单列于[robustness.json](../research/results/robustness.json)。
门按对象执行，不影响同批其他对象。风险和覆盖率按每条真实测量转移统计，部分轴保持仍计入。
